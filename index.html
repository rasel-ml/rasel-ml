FontLens

A fully offline Android font viewer and inspector app.

Features:
  • Works completely offline and needs no permissions.
  • Browse & preview local font files (.ttf, .otf)
  • Live editable font preview with size, bold, italic controls
  • Glyph keyboard to display every character in a font
  • Metadata viewer and editor
  • Favorites system
  • Support for multiple sample texts with configurable priority
